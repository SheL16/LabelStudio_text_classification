# LabelStudio_text_classification

Sentiment Classification Dataset (Label Studio)

Разметка отзывов покупателей по тональности (Positive / Negative / Neutral). Учебный проект, разметка выполнена вручную в Label Studio.

Данные
Источник: products1.csv (отзывы с платформ Amazon и Flipkart).
Задач: 149.
Распределение меток
Платформа	Задач	Positive	Negative	Neutral
Amazon	77	30	21	26
Flipkart	72	24	29	19
Итого	149	54	50	45
